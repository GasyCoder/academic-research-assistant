## 0.4.0

Historical feature release. The following capabilities were added since the 0.3.0 baseline;
preparation/audit records document the checks performed before its release.

- Academic Writing, Research Profile, Scientific Review and Citation Integrity Skills.
- Optional Discipline Profiles with explicit selection, precedence and validation.
- Local Markdown, conservative LaTeX and read-only DOCX inspection, protected prose, source
  mapping and unapplied replacement proposals.
- Separate read-only Crossref/OpenAlex/Zotero tools and optional Vale; explicit consent,
  provenance, candidate/disagreement reporting and limits.
- Regressions hardening format protection/mapping, HTTP redirects/backoff, credential
  redaction and metadata comparison. Metadata cannot establish claim support.
- Owner-approved Apache-2.0 licence, matching package/plugin metadata and packaged licence copies.
- Supported Node 20/22 development restored with bounded Vitest 4.1.12 and strict-engine CI installs.
- Private vulnerability reporting activation/verification documented as an owner gate during preparation.
- Distribution preparation: local Skills plugin, setup/config/privacy/contribution docs,
  examples, version/link validation and independent package-install checks.
